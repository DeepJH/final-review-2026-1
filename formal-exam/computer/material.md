# [x]简述题

- [x]重要！简述程序中断方式和DMA方式在数据传送过程中的主要区别。
    - answer
        - | 比较维度 | 程序中断方式 | DMA方式 |
            | --- | --- | --- |
            | **控制核心** | CPU负责全程的传送控制 | DMA控制器（DMAC）接管总线控制 |
            | **请求时机** | 一条指令执行结束时（每条指令的执行周期末尾） | 每个字/块准备就绪时（每个存取周期/总线周期末尾） |
            | **响应开销** | 需要保护现场、恢复现场，开销大 | 仅需暂停CPU一个总线周期（周期挪用），开销极小 |
            | **并行度** | CPU与外设串行或部分并行，数据传送时CPU被完全占用 | CPU与外设高度并行，传送时不占用CPU资源 |
- [x]重重要！解释指令\机器\时钟周期，概念和关系
    - answer
        - **概念：**
            - **时钟周期（Clock Cycle）：** 是计算机中最基础、最小的时间单位。
            - **机器周期（Machine Cycle）：** 又称CPU周期。通常定义为CPU从内存中读取一条指令字或一个数据字的最短时间。
            - **指令周期（Instruction Cycle）：** CPU取出并执行一条指令所需的全部时间。
        - **关系：**
            - 指令周期 $\ge$ 机器周期 $\ge$ 时钟周期。
            - 关系图：**指令周期 $\rightarrow$ 多个机器周期 $\rightarrow$ 多个时钟周期（节拍）**。
        - note
            - 哲学
                - **时钟周期**是计算机的“心跳”，每跳动一下，硬件状态就发生一次微小的改变（如触发器翻转）。
                - **机器周期**是硬件操作的“基本步长”，比如去内存拿个东西，刚好需要走这几步。
                - **指令周期**是软件眼中的“一次呼吸”，完整地吐故纳新（取指到执行完毕）才算完成一个大动作。

- [x]简述硬布线控制器和微程序控制器的优缺点。
    - answer
        - | 控制器类型 | 优点 | 缺点 | 核心思想 |
            | --- | --- | --- | --- |
            | **硬布线控制器** (RISC常用) | 速度极快（完全由纯组合逻辑电路延迟决定） | 结构繁琐、设计复杂、调试困难，且**极难扩展或修改** | 用纯硬件电路（门电路、触发器）硬编码实现控制信号 |
            | **微程序控制器** (CISC常用) | 结构规整、设计简单、调试修改方便，**易于扩充新指令** | 执行速度慢（每条微指令都需要从控制存储器CM中读取，增加了访存开销） | 将控制信号作为“微指令”像编软件一样存储在ROM中 |
        - note
            - 哲学
                - **硬布线**是“一锤子买卖”：把逻辑全部做死在芯片线路上。跑得像疯狗一样快，但如果发现有bug或者想加新指令，对不起，请重新去台积电投片流片。
                - **微程序**是“以柔克刚”：在硬件内部又搞了一套“微软件”（微码）。虽然每一步都要查表（读CM）导致变慢了，但想改指令或者修bug，只需要重写那段微码ROM即可。

- [x]简述什么是寻址方式，列举至少4种常见数据寻址方式。简要说明特点。(只写最简单的4种)
    - answer
        - **什么是寻址方式：** 寻找操作数地址或者下一条将要执行的指令地址的方法（分为数据寻址和指令寻址）。这里主要讨论数据寻址。
        - **4种最简单的常见数据寻址方式及特点：**
            1. **立即寻址（Immediate Addressing）：**
                - *特点：* 操作数直接包含在指令字中（形式地址 $A$ 就是操作数本身）。
                - *优缺点：* 速度最快（取指时操作数一并拿到，无需访存），但操作数大小受指令字长限制。
            2. **寄存器寻址（Register Addressing）：**
                - *特点：* 操作数在CPU内部的通用寄存器中，指令中给出的是寄存器编号 $R_i$。
                - *优缺点：* 速度极快（寄存器访问远快于内存），不需要访问主存，但寄存器数量有限。
            3. **直接寻址（Direct Addressing）：**
                - *特点：* 指令字中的形式地址 $A$ 就是操作数在内存中的有效地址 $EA$（即 $EA = A$）。
                - *优缺点：* 简单直观，执行阶段只需访问一次内存；但有效地址范围受指令字中地址字段长度的限制。
            4. **间接寻址（Indirect Addressing）：**
                - *特点：* 指令中给出的地址是操作数地址的指针（即 $EA = (A)$，形式地址指向一个存放有效地址的内存单元）。
                - *优缺点：* 扩大了寻址范围，便于编制循环程序；但执行时需要多次访问内存（至少2次），速度较慢。
        - note
            - 哲学
                - **立即寻址**：“把外卖直接拍你脸上”，伸手就能吃。
                - **寄存器寻址**：“东西就在你兜里”，摸出来就能用。
                - **直接寻址**：“告诉你外卖在302教室”，你去302拿了吃。
                - **间接寻址**：“告诉你去302看黑板，黑板上写着外卖在508教室”，套娃行为，最累但能实现复杂调度。

- [x]0的各种码表示形式，哪个是唯一的。
    - answer
        - **以8位字长为例，数值 0 的各种码表示：**
            - **[原码]** 0 有两种表示：$+0 = 00000000$ ， $-0 = 10000000$ （不唯一）
            - **[反码]** 0 有两种表示：$+0 = 00000000$ ， $-0 = 11111111$ （不唯一）
            - **[补码]** 0 有**唯一**的表示：$00000000$ （因为 $-0$ 的反码 `11111111` 加 1 后发生进位溢出，结果也是 `00000000`）
            - **[移码]** 0 有**唯一**的表示：$10000000$ （移码通常用于浮点数的阶码，偏置常数为 $2^{n-1}$，即在真值上加 $10000000$）
        - **结论：** 在现代计算机中，**补码（和移码）** 形式下的 0 表示是**唯一**的。
        - note
            - 计算
                - 移码
                    -补码符号取反
            - 哲学
                - 为什么计算机最后都统一用补码？因为原码和反码里有 $+0$ 和 $-0$。如果 0 有两种活法，那么 CPU 在判断 `if (x == 0)` 的时候就要做两次硬件判断，既浪费电路又影响效率。
                - 补码把 $-0$ 强行消灭了，把它变成了 $-128$（对于8位），成功让 0 达成了“全天下独一无二”的纯净状态，不仅省了判断逻辑，还顺便让补码能多表示一个负数绝对值极限。

- [x]cache和主存地址映射方式有：{answer}
    - answer
        - 直接映射
        - 全相连映射
        - 组相连映射
    - note
        - 直接映射：每个主存块只能映射到 Cache 中唯一固定的一个特定行。
        - 全相连映射：主存中的任意一个块，都可以放入 Cache 的任意一个空闲行中。
        - 组相连映射：把 Cache 分成了若干个“组”（Set）。主存块先通过取模算好自己属于哪一个组（直接映射的思路），进入这个组之后，可以任意挑选该组内的具体行（全相连映射的思路）。
        - 把内存的数据放 cache 里，是为了快一点。

# 约束
只需要其中的`重要定义`，其他的都不需要。
- `重要定义`它是`重要内容`中的`关键定义`。
    - `重要内容`
        - 在学习要点中出现有相似的多个小节，说明这是`重要内容`。
            - 例如：第一章-学习要点-辩证唯物主义物质范畴、世界的物质统一性。这是 2 个相似的小结，他们都在讲物质，说明这`是``重要内容`，要他们的相关内容。
            - 例如：第一章-学习要点-在实践中不断增强思维能力。这只有1个相似的小结，说明这`不是``重要内容`，不要他们的相关内容。
    - `关键定义`
        - 是内容关键的陈述句，说明这是`关键定义`
            - 例如：物质范畴是一切唯物主义哲学的理论基石。这是内容关键的陈述句，`是``关键定义`，要这句话的原文。
            - 例如：从古至今，唯物主义对物质的理解，经历了从朴素到科学、从片面到比较全面的过程。古代朴素唯物主义用某一种或几种物质作为本原来解释世界，在当时具有合理性和进步性。这只是简单的次要陈述句，`不是``关键定义`，不要这句话。
        - 多点展开的内容，，说明这是`关键定义`
            - 例如：
                - 第一，坚持了唯物主义一元论，同唯心主义一元论和二元论划清了界限。
                - 第二，坚持了能动的反映论和可知论，批判了不可知论。
                - 这些`是``关键定义`，要这句话的原文。
